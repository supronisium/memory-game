# Memory Game

Небольшая браузерная игра на развитие памяти, в которой необходимо находить одинаковые пары карточек. 
Игрок поочерёдно открывает карточки, запоминает их позиции и старается завершить игру с минимальным количеством ходов.

## Возможности

* Игровое поле размером 4×4, состоящее из 16 карточек и 8 пар иероглифов.
* Автоматическое случайное перемешивание карточек перед началом каждой партии.
* Отображение количества выполненных ходов и уже найденных пар.
* Экран с результатом после завершения игры.
* Локальная таблица рекордов с десятью лучшими результатами.
* Сохранение результатов в `localStorage`, благодаря чему рекорды не исчезают после перезапуска приложения.
* Исключение повторяющихся записей в списке лучших результатов.
* Полностью автономная реализация без сторонних библиотек и фреймворков.

## Правила игры

1. Нажмите на любую закрытую карточку, чтобы открыть её и увидеть иероглиф.
2. Затем выберите вторую карточку:
   * если иероглифы одинаковые, обе карточки фиксируются в открытом состоянии и отмечаются зелёным цветом;
   * если иероглифы различаются, спустя время обе карточки автоматически закрываются.
3. Повторяйте действия до тех пор, пока все 8 пар не будут найдены.
4. Один ход соответствует попытке подобрать пару, то есть засчитывается в момент открытия второй карточки. Побеждает результат с наименьшим количеством ходов.

Во время обратной анимации несовпавших карточек взаимодействие с остальными элементами игрового поля временно отключается.

## Структура интерфейса

### Верхняя панель

В верхней части приложения располагаются:

* название игры;
* кнопка **New game**, которая завершает текущую партию и создаёт новую игру с тем же размером поля;
* кнопка **Lider table**, открывающая список лучших результатов.

### Статистика

Информационная панель отображает текущий прогресс игрока:

* **Number of moves: 5** — количество попыток подобрать пару в текущей партии;
* **Number of pairs:** — число уже открытых совпадений в формате `1 / 8`.

### Игровое поле

Карточки располагаются в сетке 4×4 и переворачиваются с помощью плавной 3D-анимации.

После успешного совпадения пара получает визуальное выделение и становится недоступной для повторного нажатия.

### Всплывающие окна

В приложении предусмотрены два основных модальных окна.

**Win** - окно победы
**Lider table** - окно вывода лидеров

Оба модальных окна можно закрыть нажатием на кнопку **Close** либо кликом по затемнённой области за пределами окна.

## Используемые технологии

* **HTML5** — исходный `body` не содержит готовой разметки: необходимые элементы интерфейса создаются программно с помощью JavaScript.
* **CSS3** — используется для построения сеток и flex-контейнеров, 3D-преобразований, переходов и keyframes-анимаций.
* **JavaScript** — игровая логика реализована на чистом JavaScript без сторонних фреймворков и библиотек.
* **localStorage** — применяется для постоянного хранения результатов таблицы лидеров в браузере.

### Системные требования

Для работы приложения достаточно современного браузера с поддержкой актуальных веб-стандартов, например Chrome, Firefox, Edge или Safari.

Устанавливать Node.js, npm, дополнительные сборщики или другие инструменты разработки не нужно.

### Вариант 1. Открытие `index.html`

1. Скачайте репозиторий или клонируйте его в выбранную директорию.

2. Откройте файл `index.html` в современном браузере.
Важно: Если игра не запустилась - откройте ее в VS Code в режиме просмотра и эмуляции сервера.
